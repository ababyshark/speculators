# GLM-5.3 MTP 投机解码评测终局报告（2026-11-11）

## 一、测试矩阵全景（35 机新容器 vllm 0.30.0 / NPU TP16）

### 1.1 serving 确定性（temp=0 同 prompt 两遍逐字符比对）
| 配置 | 32K 长上下文 | 短上下文对照 |
|---|---|---|
| W4A8 + MTP×5 | **0/24 自洽**（字符一致 0.01-0.30，al 2.1-2.4） | 0/8 自洽 |
| W4A8 + 关 prefix cache | 0/24 自洽 | — |
| W8A8 + MTP×5 | **0/24 自洽**（al 2.2-2.6） | 0/8 自洽 |

→ **贪心解码全局非确定，与量化格式、prefix cache 均无关 → vllm-ascend kernel 层非确定性**

### 1.2 精度×一致性矩阵（4 场景 × 6 长度 × 3 遍，植入可验证答案）
| 任务类 | W4A8 | W8A8 |
|---|---|---|
| 英语/中文事实检索（1K-32K） | **100% 准确**，个别格格式波动 | 100% 准确，6/6 全稳定 |
| 大数算术 | **0-67%，三遍三个不同错误答案** | 0-33%，含“一致地错” |
| 代码模运算 | 0-100% 不稳定 | 0-100% 不稳定 |

→ 算术崩坏两版同病；检索类 margin 大不受微扰影响，数字类 margin 小被 kernel 噪声翻转

### 1.3 修正口径重评训练成果（N=3 均值±std）
| 评测集 | A_float | B_v20（xql on-policy 训练） | 差值 |
|---|---|---|---|
| xql in_eval | 3.307±0.048 | 3.050±0.020 | −0.257 显著 |
| xql held_eval | 3.606±0.039 | 3.479±0.060 | −0.127 显著 |
| 通用 on-policy 32 | 3.350±0.081 | 2.681±0.006 | **−0.668 显著** |

→ **九连负定量坐实 + 灾难性遗忘模式**（域外损失≫域内）

## 二、核心发现汇总（按重要性）
1. **serving 全局非确定性（kernel 层）**——所有单遍评测数字 ±0.07-0.30 噪声；算术/数字类任务输出不可复现
2. **长上下文（32K）接受率腰斩**：in-domain 案例拼接 2.1-2.7 vs 短文本 3.3+ ——生产"部分场景接受率低"的主场景特征
3. **增训八连负 → 九连负，降噪后全部显著**：方法层修复（on-policy/agree 过滤/float 写回/自洽目标）全部做完仍为负，且伴随灾难性遗忘
4. 量化格式（W4A8 vs W8A8）不影响以上任何结论

## 三、交付结论与建议
1. **MTP drafter：官方 W4A8 包原样使用，不增训**
2. **生产优化方向改为**：① 服务侧（vllm-ascend kernel 确定性排查/batch_invariant 路线，建议提报）② 流量侧（32K+ 场景考虑降低 num_spec 或动态投机长度）
3. **评测规范**（后续项目强制）：新环境先过自洽性 gate；对比 N≥3 均值±std；差值 > 噪声带才认定方向
