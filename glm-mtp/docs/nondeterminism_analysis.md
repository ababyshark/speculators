# GLM-5.3 W4A8 serving 非确定性发现与评测方法论修正（2026-11-10）

> 结论先行：**GLM-5.3 W4A8 的 vllm-ascend serving 在贪心解码下存在全局非确定性**——
> 同一 prompt、同一实例、temp=0 连续两遍，输出完全不同（0/24 自洽，字符一致率 0.01-0.30）。
> 此前所有单遍聚合口径的训练评测（v13-v20，九连负）**方向可信但幅度不可信**
> （逐次接受率噪声 ±0.2-0.3，与报告的负增益幅度同量级）。

## 一、发现过程

| 步骤 | 操作 | 结果 |
|---|---|---|
| 1 | 构造 32K 长上下文评测集（内部案例拼接 ~30.5K token + 格式锁定问题，24 条） | 之前测得 A 原始 = 3.797（单遍聚合，"长上下文无影响"的结论） |
| 2 | 新增自洽性维度：每条 prompt 跑两遍（temp=0、同实例、顺序执行），逐字符比对输出 | **0/24 自洽**（长 32K 与短 2K 对照全部不一致），字符一致率 0.01-0.30 |
| 3 | 逐请求接受率实测（两遍分别计量） | 长集 2.10/2.28、2.21/2.35；短对照 2.69/2.95——**同 prompt 两遍接受率差 ±0.2-0.3** |
| 4 | 对照实验：--no-enable-prefix-caching 重跑 | **仍不自洽**（初步：cons 0.055-0.162）→ prefix caching 非唯一根因 |

## 二、现象特征

1. **级联发散**：自回归解码中一个 token 翻转即导致后续完全不同——字符一致率低不等于
   巨大数值噪声，可能只是**微小 logit 噪声 + 级联**（NPU 算子归约顺序不确定的典型表现）
2. **与 2026-10-05 DeepSeek-V4 栈异常同构**（mtp/1005/51 文档）：该案例中同一实例
   同 prompt 跑两遍仅 5/24 一致，且分歧 100% 落在 >256 token 多块路径——当时假设为
   prefix-cache 块复用 bug；本次 GLM-5.3 关闭 prefix caching 后仍复现 → 根因更深
   （候选：NPU 算子非确定性、MTP 投机路径的 verify 非确定性、DSA indexer topk 平局）
3. **与机器/容器无关的确认需求**：本次在 35 机新容器（nju nightly v0.30.0-a3），
   40 机（vllm_ascend v0.30.0 nightly）未测自洽性——需补测以确认普遍性

## 三、对历史评测结论的影响

| 历史结论 | 重新评估 |
|---|---|
| 九连负（v13-v20 训练全部劣于 init） | **方向可信**（9/9 同向，符号检验 p≈0.002）；**幅度不可信**（-0.13~-0.35 落在 ±0.2-0.3 噪声带）|
| "长上下文无影响（3.797）" | 单遍聚合口径，未测自洽性——**该数字本身带噪声，且非确定性被掩盖** |
| "MTP 层量化零损失 / 0.145 损失" | 同上，需多遍平均复测 |
| 直连训练 +17.5pt 不迁移 | 契约错配结论不变（该结论基于配对比较），幅度待复测 |
| 八连负的机制解释（饱和+漂移） | 仍成立，但需要在降噪后的口径下重新定量 |

## 四、修正后的评测方法论（v2 口径）

1. **每条 prompt 跑 N=3 遍**（temp=0），接受率取 N 遍均值，报告 ±std（噪声条）
2. **模型对比 = 同集同实例配对**（A 与 B 先后在同一 serving 上测），差值 > 噪声带才算增益
3. **评测集 ≥64 条**（32 条子集方差 ±0.2-0.4 已实证）
4. **先测 serving 自洽性**作为 sanity gate（新环境/新配置必须先过）
5. 若确认 NPU 算子级非确定性：尝试确定性开关（算子确定性模式/单算子精度配置），
   无法消除则以噪声量化口径为准

## 五、重评计划（当前执行）

对最新训练成果重评（35 机新容器，native/A_float/B_v20_float 三方、同集同实例）：
- 训练成果：hybrid_B_v20_float（xql 域训练最优）、hybrid_B_v19_float（cmb 域）
- 基线：hybrid_A_init_float（init float）与 native
- 评测集：xql in32/held32 + 通用 on-policy 32
- 每集 N=3 遍，报告均值±std 与配对差值
- 判决标准：配对差值绝对值 > 合并噪声带（~±0.15）才认定方向
